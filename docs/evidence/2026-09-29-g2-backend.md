## Acceptance and limitations

- **Passed on the private path:** Three independent fault runs per service; one episode and incident per fault; ordered unique sequence 1–5; technical state `RECOVERED` with analyst status `OPEN`; five immutable system audit entries; normal and telemetry-gap controls with no detections or incidents; three `MISSING` KPI windows per gap control; no fabricated zero rank. All fault detections had the manifest model version and finite ranks.
- **Protected public path remains unverified:** Anonymous `/api/simulator/runs/{runId}` returned 401 and the existing controller's role/CSRF tests passed, but no real supervisor session started a public run. The only existing local users had `ANALYST` roles. Automatic approval review rejected creating a temporary `SUPERVISOR` account because it would expand privileged access. That action was not retried or bypassed.
- **Browser/UI remains unverified:** Browser control was unavailable in this session, so David's display comparison on this commit is still needed. The protected incident detail/detections/timeline responses were verified in `ServiceScenariosIT` with a test login, not a real browser login.
- **Gate decision:** Keep G2 **PARTIAL** until a user-authorized supervisor session completes the public path and David checks displayed values. Keep PR #35 draft and unmerged while that check is outstanding. Preserve the separate commits; use a regular merge commit when the gate passes.
