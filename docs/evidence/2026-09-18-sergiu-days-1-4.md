## Reproduce

Use Python 3.11+ and JDK 21. Activate an isolated Python environment and install
the existing `requirements-dev.txt`; no dependency versions were changed.

```text
python scripts/check-contracts.py
python -m unittest discover -s tests -v
python -m unittest discover -s services/ml-service/tests -v
```

On Windows:

```powershell
.\mvnw.cmd -pl services/event-generator,services/processor -am verify
```

On Linux/macOS use `./mvnw` instead. `JAVA_HOME` must point to JDK 21, not Java 8.
This run used Python 3.13.9, an isolated `.venv`, Maven wrapper 3.9.16 and a
checksum-verified portable Temurin JDK 21.0.12.1+1. System defaults were unchanged.
