The first audit attempt started these actual scenarios, then stopped on the
ambiguous back-link selector. The corrected audit **resumed those same real
runs**, validating their status/scope/scheduled times through REST instead of
rescheduling, resetting data or substituting fixtures. It completed successfully
in 5.7 minutes, after both eight-minute profiles genuinely finished.

   geography access; stale CSRF denied. ANALYST cannot start or read scenario runs.

   selected Orhei and focused Region field were preserved.
4. ANALYST self-claim; SUPERVISOR assignment/reassignment; investigation and comments;

   Reassignment disabled the previous analyst's comment control and API access.
5. Premature resolution rejected while technically active. After real recovery,
   **Awaiting analyst resolution** remained visible. Both roles explicitly resolved

6. Actual generator unavailability showed uncertain failure with no invented server
